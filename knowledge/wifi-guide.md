# 公司 Wi-Fi 连接指南（模拟知识库）

> 本文为 RAG 测试编写的虚构资料。网络名称、服务地址和操作流程仅供演示，不代表真实公司配置。

## 公司 Wi-Fi 如何连接？

员工无线网络名称（SSID）为 `DemoCorp-Staff`。请使用公司管理的电脑或手机连接，认证方式为 WPA2/WPA3 企业认证。

1. 打开设备的无线网络设置，选择 `DemoCorp-Staff`。
2. 输入员工账号（例如 `zhangsan@demo.example.com`）和员工账号密码，无需申请单独的 Wi-Fi 密码。
3. 按公司设备管理配置完成服务器证书校验，认证服务器域名为 `radius.demo.example.com`；证书异常时停止连接并联系 IT，不要关闭校验。
4. 连接成功后打开内部办公门户，确认网络可用。

访客使用 `DemoCorp-Guest`，由接待员工申请当日访客凭证；访客网络不能访问内部系统。

## Wi-Fi 无法获取 IP 怎么办？

设备显示“无法获取 IP”，或 IPv4 地址为 `169.254.x.x` 时，按以下顺序排查：

1. 确认 IPv4 设置为自动获取 IP 地址和 DNS，取消手动配置。
2. 关闭 Wi-Fi 后重新开启，忘记 `DemoCorp-Staff` 并重新认证。
3. Windows 可在命令提示符执行 `ipconfig /release`，再执行 `ipconfig /renew`；Mac 可在网络设置的 TCP/IP 页面点击“续租 DHCP 租约”。
4. 仍然失败时提交 IT 工单，附设备名称、办公地点、故障时间和网络设置截图。不要自行填写其他员工的 IP 地址。
