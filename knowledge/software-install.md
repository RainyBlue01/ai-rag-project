# 软件安装与权限申请（模拟知识库）

> 本文为 RAG 测试用虚构制度。软件分类、审批方式和处理时间仅供演示，不代表真实公司的授权政策。

## 如何申请软件安装权限？

公司管理的电脑默认不向员工提供长期本地管理员权限。软件中心已有的软件可按页面提示自助安装；提示需要管理员权限或软件未上架时，按以下流程申请：

1. 在 IT 服务门户选择“软件服务 → 软件安装申请”。
2. 填写软件名称、版本、官方下载地址、工作用途、设备资产编号及期望安装时间；付费软件还需说明许可证来源或预算。
3. 直属主管审批业务需求，IT 审查兼容性、来源和安全风险；涉及采购时，由采购部门确认授权。
4. 审批完成后由 IT 远程安装或通过软件中心下发，通常在 2 个工作日内处理。
5. 确需员工自行安装时，由 IT 按工单批准临时提权，最长 2 小时，到期自动回收。不得借用他人的管理员账号。

## 哪些软件禁止安装？

以下软件禁止在公司设备上安装：

- 盗版、破解软件，以及绕过许可证校验的激活工具。
- 含木马、挖矿程序或恶意插件的软件。
- 未经批准的远程控制工具、网络代理和 VPN 客户端。
- 用于私人娱乐的游戏及赌博软件。
- 来源不明、签名异常，或经 IT 评估存在重大安全风险的软件。

工作所需的远程工具或网络工具须先完成审批。开源软件也需要遵守许可证和安全审查要求，并非一律禁止。发现误装软件时停止使用并提交 IT 工单，由 IT 协助卸载和排查。
